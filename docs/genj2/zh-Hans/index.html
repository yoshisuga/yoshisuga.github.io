GenJ2

适用于 iPhone 和 iPad 的 J2ME 与 iAppli 模拟器

GenJ2 可在 iPhone 或 iPad 上运行 J2ME（Java ME）游戏和日本的 iAppli（DoJa）应用。内置四款原创游戏，可立即试玩，也可以导入你自己的 .jar 文件。

需要帮助或发现了问题？
请在 Discord 上提问，或在 GitHub 上提交 issue。请附上你的设备型号、iOS 版本、App 版本和游戏名称。

开始使用

  • 导入游戏：在游戏库中点按 +，选择 .jar 文件（iAppli 需同时选择 .jar 与 .jam、.sp 文件，或整个文件夹或 .zip）。也可以通过隔空投送、“文件”App 或共享表单导入。
  • 开始游戏：点按游戏。使用屏幕上的数字键盘或方向键，以及屏幕下方的软键。点按 ••• 按钮打开菜单：存取状态存档、设置、手机外观等。
  • 设置：游戏库上的齿轮可进行 App 全局设置。每个游戏也可以有自己的设置（屏幕尺寸、缩放、平滑、帧率、声音、软键代码）。

常见问题

在哪里获得游戏？
GenJ2 不包含也不会下载任何第三方游戏。请导入你有权使用的文件。

游戏无法启动，或画面、声音不正常。
打开该游戏的设置，尝试更换屏幕尺寸、缩放方式或帧率。对于 iAppli 游戏，请确认 .jam 文件（以及 .sp 文件，如有）已与 .jar 一同导入。如果仍然不行，请在 Discord 或 GitHub 上告诉我们游戏名称。

游戏中的软键或方向键无效。
不同手机厂商的游戏所需的键码不同。在该游戏的设置中更改软键代码（标准、Motorola、Siemens），或开启方向键发送 8 / 4 / 6 / 2。

什么是状态存档？
可随时通过 ••• 菜单保存和恢复游戏。每个游戏有一个免费存档位。GenJ2 高级版可为每个游戏解锁 10 个存档位，并在你离开 App 时自动存档。

高级版包含什么？
一次性购买（非订阅）：每个游戏 10 个存档位、自动存档，以及更多手机颜色和质感。所有游戏和设置均免费。

如何恢复购买？
设置 → 高级版 → 恢复购买，需登录购买时使用的 Apple ID。在你的其他设备上同样有效。

如何获得复古手机外观？
在游戏中打开 ••• → 手机外观（或 设置 → 控制），可选择直板或翻盖手机、颜色、拉伸或正常比例，以及金属光泽。

支持 iPhone Duo 吗？
支持：折叠时一屏显示游戏、另一屏显示控制，纵向折叠，全屏横向，以及外屏。

GenJ2 需要联网吗？
不需要。请参阅隐私政策。
