GenJ2

iPhone・iPad 用 J2ME・iアプリ エミュレーター

GenJ2 は、J2ME（Java ME）のゲームや日本のiアプリ（DoJa）を iPhone と iPad で遊べるエミュレーターです。すぐに試せるオリジナルゲームを4本収録しており、お手持ちの .jar ファイルも取り込めます。

お困りですか？ 不具合を見つけましたか？
Discord で質問するか、GitHub で issue を作成してください。お使いの機種、iOS のバージョン、アプリのバージョン、ゲーム名を添えていただけると助かります。

はじめに

  • ゲームを取り込む：ライブラリの + をタップして .jar ファイルを選びます（iアプリは .jar と .jam、.sp ファイルを一緒に、またはフォルダや .zip ごと）。AirDrop、「ファイル」アプリ、共有シートからも取り込めます。
  • 遊ぶ：ゲームをタップします。画面上のテンキーや十字キー、画面下のソフトキーで操作します。••• ボタンでメニューが開き、ステートセーブ／ロード、設定、ケータイスキンなどを使えます。
  • 設定：ライブラリの歯車でアプリ全体の設定ができます。ゲームごとの設定（画面サイズ、拡大方式、スムージング、フレームレート、サウンド、ソフトキーコード）も可能です。

よくある質問

ゲームはどこで手に入りますか？
GenJ2 にはサードパーティ製ゲームは含まれておらず、ダウンロードもしません。利用する権利のあるファイルを取り込んでください。

ゲームが起動しない、または表示や音がおかしい。
そのゲームの設定で、画面サイズ、拡大方式、フレームレートを変えてみてください。iアプリの場合は、.jar と一緒に .jam ファイル（および .sp ファイル）を取り込んだか確認してください。それでも直らない場合は、ゲーム名を Discord か GitHub でお知らせください。

ゲーム内でソフトキーや矢印キーが効かない。
携帯メーカーによって期待されるキーコードが異なります。そのゲームの設定でソフトキーコード（標準、Motorola、Siemens）を変更するか、矢印キーで 8 / 4 / 6 / 2 を送信をオンにしてください。

ステートセーブとは？
••• メニューから、いつでもゲームの状態を保存・復元できます。無料ではゲームごとに1つのスロットが使えます。GenJ2 プレミアムでは、ゲームごとに10スロットと、アプリを離れるときの自動セーブが使えるようになります。

プレミアムには何が含まれますか？
一度きりの購入（サブスクリプションではありません）で、すべてのゲームで10個のセーブスロット、自動セーブ、さらに多くのケータイの色と仕上げが使えます。ゲームと設定はすべて無料です。

購入を復元するには？
設定 → プレミアム → 購入を復元 で、購入時の Apple ID でサインインして行います。他のデバイスでも使えます。

レトロなケータイの見た目にするには？
ゲーム中に ••• → ケータイスキン（または 設定 → コントロール）を開き、ストレート型か折りたたみ型、色、引き伸ばしか通常の比率、メタリックの輝きを選べます。

iPhone Duo で使えますか？
はい。折りたたんで片方の画面にゲーム、もう片方にコントロールを表示、縦向きの折りたたみ、全画面横向き、外側の画面に対応しています。

インターネット接続は必要ですか？
いいえ。プライバシーポリシーをご覧ください。

このアプリについて

GenJ2 は、オープンソースのphoneME ベースのエミュレーターをもとにした独立したプロジェクトです。ライセンスは 設定 → 謝辞 に記載しています。

Java は Oracle およびその関連会社の商標です。iAppli（iアプリ）は株式会社NTTドコモの商標です。GenJ2 は独立したプロジェクトであり、これらの企業とは関係がなく、承認も受けていません。
