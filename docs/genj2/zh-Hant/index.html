GenJ2

適用於 iPhone 和 iPad 的 J2ME 與 iAppli 模擬器

GenJ2 可在 iPhone 或 iPad 上執行 J2ME（Java ME）遊戲和日本的 iAppli（DoJa）應用程式。內建四款原創遊戲，可立即試玩，也可以匯入你自己的 .jar 檔案。

需要協助或發現問題？
請在 Discord 上提問，或在 GitHub 上提交 issue。請附上你的裝置型號、iOS 版本、App 版本和遊戲名稱。

開始使用

  • 匯入遊戲：在遊戲庫中點一下 +，選擇 .jar 檔案（iAppli 需同時選擇 .jar 與 .jam、.sp 檔案，或整個資料夾或 .zip）。也可以透過 AirDrop、「檔案」App 或分享表匯入。
  • 開始遊戲：點一下遊戲。使用螢幕上的數字鍵盤或方向鍵，以及螢幕下方的軟鍵。點一下 ••• 按鈕開啟選單：存取狀態存檔、設定、手機外觀等。
  • 設定：遊戲庫上的齒輪可進行 App 全域設定。每個遊戲也可以有自己的設定（螢幕尺寸、縮放、平滑、影格率、聲音、軟鍵代碼）。

常見問題

在哪裡取得遊戲？
GenJ2 不包含也不會下載任何第三方遊戲。請匯入你有權使用的檔案。

遊戲無法啟動，或畫面、聲音不正常。
開啟該遊戲的設定，嘗試更換螢幕尺寸、縮放方式或影格率。對於 iAppli 遊戲，請確認 .jam 檔案（以及 .sp 檔案，如有）已與 .jar 一同匯入。如果仍然不行，請在 Discord 或 GitHub 上告訴我們遊戲名稱。

遊戲中的軟鍵或方向鍵無效。
不同手機廠商的遊戲所需的鍵碼不同。在該遊戲的設定中更改軟鍵代碼（標準、Motorola、Siemens），或開啟方向鍵傳送 8 / 4 / 6 / 2。

什麼是狀態存檔？
可隨時透過 ••• 選單儲存和還原遊戲。每個遊戲有一個免費存檔位。GenJ2 進階版可為每個遊戲解鎖 10 個存檔位，並在你離開 App 時自動存檔。

進階版包含什麼？
一次性購買（非訂閱）：每個遊戲 10 個存檔位、自動存檔，以及更多手機顏色和質感。所有遊戲和設定皆免費。

如何還原購買？
設定 → 進階版 → 還原購買，需登入購買時使用的 Apple ID。在你的其他裝置上同樣有效。

如何取得復古手機外觀？
在遊戲中開啟 ••• → 手機外觀（或 設定 → 控制），可選擇直立式或摺疊手機、顏色、拉伸或正常比例，以及金屬光澤。

支援 iPhone Duo 嗎？
支援：摺疊時一個螢幕顯示遊戲、另一個顯示控制，直向摺疊，全螢幕橫向，以及外螢幕。

GenJ2 需要連網嗎？
不需要。請參閱隱私權政策。

關於
